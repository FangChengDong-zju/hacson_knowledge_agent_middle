## 9. 评审快速验证路线

建议评审按以下顺序验证，约 3-5 分钟：

1. 打开公网部署：

   ```text
   https://hacson-knowledge-agent.streamlit.app
   ```

2. 查看首页主流程：

   ```text
   教材来源 -> 整合需求与二次反馈 -> 整合闭环证据总览
   ```

3. 展开：

   ```text
   3. 整合闭环证据总览
   4. 整合结果：图谱
   4. 整合结果：文档
   5. 整合依据：决策记录
   ```

4. 切换到：

   ```text
   资料问答：基于整合结果查询
   ```

5. 查看文档证据：

   ```text
   README.md
   docs/Agent架构说明.md
   docs/整合闭环证据.md
   report/整合报告.md
   ```
