# 需求分析

## 核心问题

多本医学教材存在大量重复、互补和表达差异。系统需要将多教材内容压缩为教学主干，同时保留来源索引，服务学生学习、教师备课和课程整合。

## 子问题拆解

1. 教材解析：支持 PDF / Markdown / TXT，并识别章节结构。
2. 知识点粒度：以可教学的概念、方法、定理、现象为基本节点。
3. 重复判定：同名、近义、英文别名、缩写需要合并；上下位概念不能误合并。
4. 教学连贯性：保留定义、关系、学习顺序；案例和细节降级为索引。
5. 压缩比：整合后主干内容不超过原始总字数 30%。
6. RAG 分块：每块约 500-800 字，重叠 50-100 字，保留教材、章节、页码元数据。

## 我们的 P1 目标

先实现可演示闭环：解析本地 7 本教材、生成图谱、输出整合决策、展示压缩比、带引用问答、教师反馈修改一条决策、生成整合报告。
