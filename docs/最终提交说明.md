## 4. 最后演示路线

建议最终提交前按以下路线检查一次：

1. 打开：

   ```text
   https://hacson-knowledge-agent.streamlit.app
   ```

2. 确认首页能看到：

   ```text
   Hacson 学科知识整合智能体
   1. 教材来源
   2. 整合需求与二次反馈
   3. 整合闭环证据总览
   ```

3. 在“1. 教材来源”上传一个小 TXT 或 MD 文件。

4. 看到类似提示：

   ```text
   已解析上传教材 X 份，生成 X 个可检索片段，将参与整合和问答。
   ```

5. 输入需求：

   ```text
   面向临床见习学生，感染相关内容保留共同主干，病例细节降级为索引。
   ```

6. 展开：

   ```text
   3. 整合闭环证据总览
   4. 整合结果：图谱
   4. 整合结果：文档
   5. 整合依据：决策记录
   ```

7. 切换左侧：

   ```text
   资料问答：基于整合结果查询
   ```

8. 问一个问题，确认系统会进入资料检索流程。
